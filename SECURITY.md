# Security policy

## Supported versions

Security fixes are applied to the latest revision of `main`. VibeWarp does not yet
maintain multiple supported release branches.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Security** tab by opening a
private vulnerability report. Include reproduction steps, affected versions, and the
potential impact when possible.

Do not open a public issue containing exploit details, credentials, private model URLs,
or personal data. If private vulnerability reporting is unavailable, open a minimal
issue asking the maintainers for a private contact channel without disclosing details.

VibeWarp downloads and runs large third-party models and tools. A report about an
upstream package or model should identify the exact source and version so it can be
distinguished from VibeWarp code.
